# MySketch

Processingで顔パーツの色・位置・角度・大きさを編集するプログラム

## 1. 実行に必要なライブラリ・ツール

| 名前 | 必要な場面 | 用途・導入方法 |
| --- | --- | --- |
| Processing 4| 起動時に必要 | スケッチを実行する環境。 |
| oscP5| 起動時に必要 | OSCメッセージの受信。Processingのライブラリで `oscP5` を検索してインストールする。 |
| netP5 | 起動時に必要 | oscP5に含まれる通信パッケージ。oscP5と一緒に導入される。 |
| FFmpeg | 「動画化」を使う場合 | 連番PNG画像をMP4へ変換する外部ツール。`libx264` が使えるビルドを用意し、実行ファイルをPATHに追加する。必要性は低いのでインストールしないでも良い気がする |

OSCを使わずに画面操作だけを行う場合も、起動時にoscP5の受信を初期化するため、oscP5が必要です。FFmpegがなくても、顔の編集・JSON操作・連番画像の録画は利用できます。

### 起動方法

1. すべての `.pde` ファイルを同じ `face` フォルダに置く。
2. Processingで `face/face.pde` を開き、Javaモードを選ぶ。
3. oscP5をインストールして、実行ボタンを押す。

画面サイズは800×880、顔の描画領域は600×700、描画・録画は30fps設定です。画面サイズ・色・ボタン配置・OSCポートなどは `conf.pde` で変更できます。

動画化を使う場合は、ターミナルで次のコマンドが実行できることを確認します。PATHに追加しない場合は、`conf.pde` の `ffmpeg_command` に実行ファイルの絶対パスを指定してください。

```sh
ffmpeg -version
```

## 2. 関数一覧

タブごとに、スケッチで定義している関数をまとめています。

### `face.pde` — 起動と毎フレームの処理

| 関数 | 役割 |
| --- | --- |
| `settings()` | 画面サイズを設定する。変数で指定するためsettings()を使う。 |
| `setup()` | 起動時に一度だけ、描画・プリセット・OSCを準備する。 |
| `draw()` | 毎フレーム、待機中の操作・アニメーション・描画・録画を処理する。 |
| `processPendingActions()` | 保存・読込とOSCの待機列を、上限件数まで順番に処理する。 |
| `drawFaceAndUI()` | 背景、補助線、顔パーツ、操作パネルの順に描く。 |

### `drawing.pde` — 描画の共通処理

| 関数 | 役割 |
| --- | --- |
| `drawText()` | 色・文字サイズ・文字の基準位置を指定して描き、描画設定を元に戻す。 |

| `drawGuideLines()` | 中央の補助線と線対称時の破線を描く。録画中は非表示。 |
| `drawPart()` | idで指定した顔パーツを、設定された位置・角度・大きさ・色で描く。 |

### `drawUI.pde` — 操作パネルの描画

| 関数 | 役割 |
| --- | --- |
| `drawUI()` | 操作パネル、選択ボタン、入力欄、スライダーを描く。 |
| `drawInputBox()` | 数値入力欄を描く。選択中は入力文字、それ以外は現在の設定値を表示する。 |
| `drawSystemButton()` | 角丸ボタンを描く。マウスが重なると背景を明るくする。 |
| `drawLockButton()` | 固定状態lockedに合わせて、ボタンの文字と背景色を変更する。 |

### `input.pde` — マウス・キーボード入力

| 関数 | 役割 |
| --- | --- |
| `mouseInside()` | 現在のマウスカーソルが指定した長方形の内側にあるか調べる。境界上は含めない。 |
| `mousePressed()` | クリックしたボタンや入力欄を調べ、対応する設定を変更する。 |
| `mouseDragged()` | ドラッグ中にスライダーと回転ダイヤルを更新する。 |
| `updateSlidersAndDial()` | マウス位置から、RGB値・回転角度・アニメーション時間を求める。 |
| `keyPressed()` | 入力欄の編集、移動・回転キー、プリセット再生を処理する。 |
| `applyBoxValue()` | 入力文字を数値に変換し、選択中の項目へ反映する。 |

### `state.pde` — 顔の状態・左右同期・プリセット

| 関数 | 役割 |
| --- | --- |
| `get_targetIdx()` | 操作対象IDを配列の添字に変換する。両方選択時は左側を返す。 |
| `targetParts()` | 操作するパーツ番号を返す。個別なら1個、両方なら2個。 |
| `isMoveLocked()` | パーツの位置・角度・大きさが固定中かを返す。partは配列番号。 |
| `isColorLocked()` | パーツの色が固定中かを返す。partは配列番号0〜8。 |
| `isFiniteValue()` | NaNと無限大を除き、通常の数値かを調べる。 |
| `normalizeAngle()` | 同じ向きを保ち、角度を0度以上360度未満にそろえる。 |
| `sync_targets()` | 両方選択中なら、アニメーションを止めて左右を同期する。 |
| `syncPair()` | 左側の色と形を、線対称モードに合わせて右側へ反映する。 |
| `moveParts()` | 指定した配列のパーツを移動・回転する。dx・dyは移動量、daは回転量。 |
| `move_target()` | アニメーションを止め、選択中のパーツを直接移動・回転する。 |
| `getColorChannel()` | colorから、指定したR・G・Bの成分を取り出す。 |
| `withColorChannel()` | 他の成分を保ち、指定したRGB成分だけを変更した色を返す。 |
| `applyColorValue()` | 選択中のパーツのRGB成分を変更する。瞼の場合は背景色を変更する。 |
| `apply_transformValue()` | 選択中の位置・角度・大きさを変更し、両方選択時は右側も更新する。 |
| `applySym()` | 左側の値valを右側へ反映する。線対称ONならX座標と角度を反転する。 |
| `copyValues()` | 2次元配列を行ごとにコピーし、元の配列と独立した新しい配列を返す。 |

| `savePreset()` | 現在の位置・形・色を、指定番号のプリセット配列に記録する。 |
| `reset_toDefault()` | 顔と操作設定をその場で初期値に戻す。登録済みプリセットは残す。 |

| `start_transition()` | 目標の位置・形・色を設定し、アニメーションを開始する。 `shortest_rotation` がtrueなら最短方向に回転する。 |

| 関数 | 役割 |
| --- | --- |
| `saveSettings()` | 保存先を選ぶ画面を開く。選択後にsaveCallback()が呼ばれる。 |

| `loadSettings()` | 読込ファイルを選ぶ画面を開く。選択後にloadCallback()が呼ばれる。 |
| `saveCallback()` | 保存処理を待機列に入れ、draw()側で実行できるようにする。 |
| `loadCallback()` | 読込処理を待機列に入れ、draw()側で実行できるようにする。 |
| `readFaceData()` | JSONの色と位置・形を検査し、準備したコピー先へ読み込む。 |
| `readColors()` | 全パーツのRGB配列を検査し、colorへ変換する。 |

| `validEyelidShape()` | 瞼形状が楕円か四角かを確認し、不正な番号ならエラーにする。 |
| `loadSelectedSettings()` | JSONをすべて検査してから、顔と操作設定をまとめて反映する。 |
| `loadAndTransitionFromJson()` | JSONの顔データを目標にして、アニメーションを開始する。 |

### `osc.pde` — OSC受信と処理

| 関数 | 役割 |
| --- | --- |
| `oscEvent()` | 受信したOSCメッセージを待機列に入れる。ここでは顔を変更しない。 |
| `oscNumber()` | OSCの整数または小数をfloatとして取り出し、異常値を確認する。 |
| `requireOscTypes()` | OSCの引数の数と型を確認する。nは整数・小数のどちらも許可。 |
| `handleOscMessage()` | OSCのアドレスを調べ、プリセット・速度・JSON読込・移動を処理する。 |

### `recording.pde` — 録画と動画書き出し

| 関数 | 役割 |
| --- | --- |
| `recordFrame()` | 録画中の顔領域を連番画像に保存し、録画マークと経過時間を描く。 |
| `prepareRecordingFolder()` | 録画フォルダを用意し、前回の連番画像を削除する。 |
| `exportVideo()` | FFmpegで連番画像を動画に変換し、別スレッドで終了とログを確認する。 |

`conf.pde` は設定値と共有変数を置くタブで、関数は定義していません。`settings()`・`setup()`・`draw()`・マウス／キーの関数はProcessingから呼ばれます。`saveCallback()`・`loadCallback()`はファイル選択後、`oscEvent()`はOSC受信時に呼ばれます。匿名クラスの `run()` は、待機中のファイル操作や動画変換の処理を実行します。

## 3. 操作方法

### 顔の編集

1. 右側のボタンで、編集する目・眉・瞼・背景を選ぶ。「両目」などを選ぶと左右をまとめて編集できる。
2. RGBスライダーまたは数値入力欄で色を変更する。
3. 回転ダイヤルまたは角度入力欄で角度を変更する。
4. X・Y・幅・高さの入力欄で位置と大きさを変更する。

Xは右方向、Yは下方向に増えます。長さの単位はピクセル、角度の単位は度です。目・瞼の位置は中心座標です。眉は線で描き、幅が線の長さ、高さが線の太さになります。

数値入力欄をクリックすると入力内容が空になり、数字を打つたびに反映されます。入力できるのは最大8文字の整数で、角度・X・Yは先頭の負号も使えます。`Backspace`で末尾を削除し、`Enter`で入力欄の選択を解除します。RGBは0〜255、幅・高さは0以上に補正されます。

### キーボード操作

入力欄が選択されていないときに使えます。英字は大文字・小文字のどちらでも同じ操作です。

| キー | 操作 |
| --- | --- |
| `↑` / `W` | 上へ5px移動 |
| `↓` / `S` | 下へ5px移動 |
| `←` / `A` | 左へ5px移動 |
| `→` / `D` | 右へ5px移動 |
| `Q` | 角度を−3度変更 |
| `E` | 角度を＋3度変更 |
| `1`〜`7` | 登録済みのプリセットへアニメーションで切り替える |

「両方」を選び、線対称がONの場合、左右のX移動量と回転量は逆向きになります。

### 線対称・瞼・補助線・固定

| 操作項目 | 動作 |
| --- | --- |
| 両方選択時：線対称 | 両方選択中の位置・角度を中央線に対して反転する。両方を選んだときや線対称を切り替えたときは、左側の値を右側へ反映する。OFFの場合は左右を同じ値にそろえる。 |
| 上瞼／下瞼 | 上下それぞれの形状を楕円・四角に切り替える。 |
| 補助線 | 中央の補助線を表示・非表示にする。録画中は非表示になる。 |
| 背色／目色／眉色の固定 | プリセットやOSCによる遷移で、指定した部分の現在色を保つ。 |
| 瞼動／目動／眉動の固定 | プリセットやOSCによる遷移で、指定した部分の位置・角度・幅・高さを保つ。 |

瞼は背景色で描くため、瞼のRGBを編集すると背景色も変わります。背景は色だけを編集でき、移動・回転・大きさの変更はできません。固定ボタンはアニメーション遷移に適用され、マウス・キーの手動編集や「読込」「初期化」は引き続き行えます。

### プリセットとアニメーション

- 下部の1〜7のボタンをクリックすると、現在の位置・角度・大きさ・色をその番号へ登録します。登録済みの番号をクリックすると上書きします。
- 再生はキーボードの1〜7、またはOSCの `/preset` で行います。
- 起動時の顔はプリセット1へ自動登録されます。
- 速度スライダーで所要時間を0.1〜5秒に変更できます。初期値は1.5秒です。短いほど速く切り替わります。

プリセットは実行中のメモリに保持され、終了すると消えます。瞼形状や固定状態などの操作設定はプリセットに含まれません。

### 初期化・JSON保存・読込

| ボタン | 動作 |
| --- | --- |
| 初期化 | 顔・線対称・瞼形状・補助線・固定状態・アニメーション時間を初期値へ戻す。登録済みプリセットは残る。 |
| 保存 | 現在の顔と操作設定をJSONへ保存する。拡張子がなければ `.json` を付ける。 |
| 読込 | JSONの顔と操作設定をその場で反映する。アニメーションは停止する。 |

JSONには9パーツのRGBと変形データ（X・Y・角度・幅・高さ）、線対称、上下の瞼形状、補助線、各固定状態、アニメーション時間を保存します。プリセット一覧は保存しません。現在のプログラムが保存する形式を使用してください。古い形式や項目不足のJSONには対応していません。読込に失敗した場合は現在の設定を保ち、コンソールへエラーを表示します。

### 録画と動画化

1. 「録画開始」をクリックする。スケッチフォルダの `frames` に `frame-0000.png` から連番画像を保存する。
2. 「録画停止」をクリックする。
3. 「動画化」をクリックする。FFmpegが画像をH.264形式の `output.mp4` に変換する。

保存されるのは600×700の顔領域です。操作パネル・補助線・REC表示は録画に入りません。録画中に「動画化」を押した場合は録画を停止してから変換します。動画変換中は録画開始と二重の動画化を受け付けません。進行状況と結果はProcessingのコンソールに表示されます。

新しく録画を開始すると、`frames` 内の `frame-*.png` は削除されます。動画化では既存の `output.mp4` を上書きします。残したい画像・動画は次の操作前に別の場所へコピーしてください。

### OSCによる外部操作

受信ポートの初期値は **12000（UDP）** です。同じPCから送る場合は `127.0.0.1`、別の機器から送る場合はこのプログラムを実行しているPCのIPアドレスを宛先にします。

| アドレス | 引数 | 操作 |
| --- | --- | --- |
| `/preset` | 整数：プリセット番号（0〜6） | 登録済みプリセットへ切り替える。画面の1〜7に対応する。 |
| `/speed` | 整数：所要時間（ms） | アニメーション時間を変更する。100〜5000msに補正する。 |
| `/loadJson` | 文字列：JSONファイルのパス | 顔の位置・形・色だけを読み込み、現在の固定状態に従って遷移する。瞼形状などの操作設定は変更しない。実行PC上の絶対パスを指定すると確実。 |
| `/movePart` | 整数：対象ID、数値：X移動量、数値：Y移動量、数値：回転量 | 対象を相対移動・回転させる。数値にはOSCの整数・小数を使える。背景は移動しない。 |

`/preset`・`/loadJson` は最短方向に回転します。`/movePart` は指定した回転方向と回転量を保ちます。両方の対象を指定した場合は、現在の線対称設定に従います。

| 対象ID | パーツ |
| --- | --- |
| 0 / 1 | 左目 / 右目 |
| 2 / 3 | 左眉 / 右眉 |
| 4 / 5 | 左上瞼 / 右上瞼 |
| 6 / 7 | 左下瞼 / 右下瞼 |
| 8 | 両目 |
| 9 | 両眉 |
| 10 | 両上瞼 |
| 11 | 両下瞼 |
| 12 | 背景 |

例：`/movePart` に `8, 10, 0, 0` を送ると、両目をX方向へ10px移動する目標を設定します。線対称ONなら左目は右へ、右目は左へ動きます。`/preset` に `0` を送ると、画面のプリセット1を再生します。
